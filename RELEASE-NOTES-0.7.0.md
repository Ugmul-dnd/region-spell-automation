# Ugmuls 5.5e Automation v0.7.0

Region Spell Automation is now **Ugmuls 5.5e Automation**, reflecting its expanded spell, region and combat automation features.

- Renamed the repository, module ID, installation folder and release package to `ugmuls-5-5e-automation`.
- Updated module and settings-window names, documentation, installation links and release URLs.
- Simplified the README, with a link to [module information and features](https://ugmul-dnd.com/foundry).
- Clarified that automations are developed using official Foundry Player's Handbook (2024) content. D&D Beyond Importer content may work but has not been tested.
- Retains the features and fixes from v0.6.1; see [the previous release notes](RELEASE-NOTES-0.6.1.md) for details.

## Installation

This release uses a **new module ID**. It is a clean install, rather than an automatic migration from `region-spell-automation`. Enable Ugmuls 5.5e Automation and use **Add Starting Spell List** to begin configuring regions. Previous settings and stored world references are not migrated or removed.

Install manifest:

```text
https://github.com/Ugmul-dnd/ugmuls-5-5e-automation/releases/latest/download/module.json
```

Requires Foundry VTT v14 and D&D5e 6.0.5 or newer; tested on Foundry build 369 and D&D5e 6.0.6. Restart Foundry and hard-refresh connected browsers after installing or updating.
